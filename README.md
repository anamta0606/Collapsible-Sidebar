Collapsible Sidebar

About the Project
This project is a responsive Collapsible Sidebar built using HTML, CSS, and JavaScript.

It allows users to expand and collapse the sidebar and navigate through different sections easily.

Features
- Expandable and collapsible sidebar
- Navigation menu
- Responsive design
- Interactive functionality
- Simple and user-friendly interface

Technologies Used
- HTML5
- CSS3
- JavaScript

Project Files
- `index.html` – Project structure
- `style.css` – Styling and layout
- `script.js` – Sidebar functionality

How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
